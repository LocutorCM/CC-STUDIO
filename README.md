# CC Studio

**Creative Vocal Reverb** — a stereo reverb plugin with five distinct vocal spaces and a pink liquid-glass interface.

## macOS compatibility

- **Minimum OS:** macOS 12 Monterey
- **CPU:** Intel x86_64
- **Plugin formats:** Audio Unit (AU) and VST3
- **Also builds:** Standalone app
- **Framework:** JUCE 8 / C++17

This project is intentionally built for Intel Macs. The macOS GitHub Actions workflow targets `x86_64` and sets the deployment target to `12.0`; it does not produce an Apple Silicon-only binary.

## Reverb modes

- **Dream** — soft, spacious vocal ambience
- **Vintage** — warm, classic reverb character
- **Dark Hall** — deep, darker cinematic space
- **Crystal** — brighter, airy reflections
- **Ethereal** — expansive, long atmospheric tails

## Controls

Mix, Decay, Pre-Delay, Size, Width, Damping, Low Cut, High Cut, Modulation and Output.

## Build on an Intel Mac

Install Xcode Command Line Tools and CMake, then run:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_OSX_ARCHITECTURES=x86_64 \
  -DCMAKE_OSX_DEPLOYMENT_TARGET=12.0
cmake --build build --config Release
```

JUCE 8.0.6 is fetched by CMake from the official JUCE repository.

## Download a build

Every push to `main` starts the **Build CC Studio (macOS Intel)** workflow. When it completes successfully, open the repository's **Actions** tab, select the successful run, and download the `CC-Studio-macOS-Intel-Monterey` artifact.

The artifact contains the AU component, VST3 bundle and Standalone app generated by that build.
